# WakayamaLPDrafts

## 用途
WakayamaLPDrafts は、和歌山WEBプロジェクトで営業候補となる店舗の調査データとLPプレビューを保存する下書き用GitHubリポジトリです。

主に `data/research/` に店舗調査JSONを置き、その情報をもとに `preview/` にLPのHTML/CSSプレビューを生成する用途で使います。

現在は、サンプル・トリミングサロンとソルドッグデザインの調査データ、ソルドッグデザインのLPプレビューが入っています。

## 注意点
AI生成された店舗情報には未確認情報が含まれる可能性があるため、住所・電話番号・営業時間・駐車場・料金・予約導線などは必ず人間が確認してから営業・公開に使います。

過去に、調査JSON側で `null`(未確認)となっている項目(駐車場台数など)が、LPプレビュー側では確定情報のように表示されてしまう不整合が見つかったことがあります。プレビューを営業・公開に転用する際は、必ず調査JSONの `notes` フィールドと照合してください。
